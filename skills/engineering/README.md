# Engineering

Skills for day-to-day code work.

- **[ask-matt](./ask-matt/SKILL.md)**: Ask which skill or flow fits your situation.
- **[code-review](./code-review/SKILL.md)**: Review a diff since a fixed point on two axes: standards and spec.
- **[codebase-design](./codebase-design/SKILL.md)**: Shared vocabulary for designing deep modules.
- **[diagnosing-bugs](./diagnosing-bugs/SKILL.md)**: Diagnosis loop for hard bugs and performance regressions.
- **[domain-modeling](./domain-modeling/SKILL.md)**: Build and sharpen a project's domain model, glossary, and ADRs.
- **[grill-with-docs](./grill-with-docs/SKILL.md)**: Relentless interview that also creates ADRs and glossary entries.
- **[implement](./implement/SKILL.md)**: Implement a piece of work from a spec or set of tickets.
- **[implement-spec](./implement-spec/SKILL.md)**: Implement a whole spec on one branch with parallel implementers.
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)**: Scan for design opportunities and turn them into a visual report.
- **[pr](./pr/SKILL.md)**: Write a focused PR body with evidence and blast radius.
- **[prototype](./prototype/SKILL.md)**: Build a throwaway prototype to answer a design question.
- **[research](./research/SKILL.md)**: Investigate a question against primary sources and capture a cited note.
- **[retro](./retro/SKILL.md)**: Retrospect on a coding session and improve the agent environment.
- **[setup-matt-pocock-skills](./setup-matt-pocock-skills/SKILL.md)**: Configure a repo's issue tracker, labels, and domain docs.
- **[tdd](./tdd/SKILL.md)**: Test-driven development with a red-green-refactor loop.
- **[to-spec](./to-spec/SKILL.md)**: Turn the current conversation into a spec.
- **[to-tickets](./to-tickets/SKILL.md)**: Break a plan or spec into tracer-bullet tickets with blocking edges.
- **[triage](./triage/SKILL.md)**: Move issues and external PRs through triage roles.
- **[wayfinder](./wayfinder/SKILL.md)**: Plan work larger than one session as a map of decision tickets.
- **[wizard](./wizard/SKILL.md)**: Generate an interactive bash wizard for human-only steps.
- **[write-notes-like-deepseek](./write-notes-like-deepseek/SKILL.md)**: Record the why and rejected options for non-trivial changes in `.agents/notes/`.
