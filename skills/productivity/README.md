# Productivity

General workflow tools, not code-specific.

- **[grill-me](./grill-me/SKILL.md)**: Relentless interview to sharpen a plan or design.
- **[grilling](./grilling/SKILL.md)**: Stress-test a plan, decision, or idea.
- **[handoff](./handoff/SKILL.md)**: Compact the current conversation into a handoff document.
- **[teach](./teach/SKILL.md)**: Teach a skill or concept over multiple sessions.
- **[to-questionnaire](./to-questionnaire/SKILL.md)**: Turn a decision into a questionnaire for someone else.
- **[wait-what](./wait-what/SKILL.md)**: Re-pitch the last message with the missing context.
- **[writing-for-agents](./writing-for-agents/SKILL.md)**: Write skills and instruction files for agents.
